# Projeto de Currículo em HTML e CSS

Este projeto consiste na criação de um currículo simples e elegante utilizando **HTML** para a estrutura e **CSS** para a estilização. O objetivo é apresentar informações profissionais de forma clara e visualmente agradável, ideal para ser compartilhado online.

---

Funcionalidades:

Estrutura semântica em HTML para organizar as seções do currículo (contatos, formação, experiência, habilidades e etc).

Estilização completa com CSS para definir cores, fontes, espaçamento e layout.

Design limpo e focado na legibilidade.

---

Como visualizar:

Para visualizar o currículo, basta abrir o arquivo index.html em qualquer navegador web.

---

Tecnologias utilizadas:

* HTML: Para a estrutura e conteúdo do currículo.

* CSS: Para a estilização.

Estrutura do Projeto

* index.html (arquivo principal HTML do currículo).

* style.css (arquivo CSS com a estilização).
